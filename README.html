ifo

Overview

The goal of ifo is to provide a simple interface to the ifo institute time series data. Feel free to open an issue if you have any suggestions.

Installation

You can install the released version of ifo from CRAN with:

install.packages("ifo")

And the development version from GitHub with:

# install.packages("pak")
pak::pak("m-muecke/ifo")

Usage

library(ifo)

climate <- ifo_business()
head(climate)
